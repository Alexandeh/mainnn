# Minecraft Pinball

Este repositorio contiene un pequeño juego de pinball inspirado en los colores de Minecraft. Para ejecutarlo necesitas Python y la biblioteca Pygame.

## Requisitos
- Python 3
- Pygame (`pip install pygame`)

## Ejecución

```bash
python minecraft_pinball.py
```

Usa las flechas izquierda y derecha para mover la paleta e impedir que la bola caiga.
